A small Python program that writes a one-line roast of a smart fridge to /output/entry.txt. The line is fixed and deterministic — the same 138-character line every run: the fridge rates groceries like a food critic, the kale gets four stars, and the midnight pizza gets a health warning and a restraining order.

## Run it

```sh
python3 main.py
```
